## 🔌 API Endpoints

### Существующие (обновлены):

1. **GET /api/admin/products**
   - Получение списка товаров
   - Параметры: `search`, `categoryId`, `isAvailable`
   - Ответ: массив товаров с фото

2. **POST /api/admin/products**
   - Создание нового товара
   - Body: все поля товара
   - Ответ: созданный товар

3. **GET /api/admin/products/[id]**
   - Получение товара по ID
   - Ответ: товар с фото и модификаторами

4. **PATCH /api/admin/products/[id]**
   - Обновление товара
   - Body: изменяемые поля
   - Ответ: обновлённый товар с фото

5. **DELETE /api/admin/products/[id]**
   - Удаление товара
   - Ответ: `{ success: true }`

### Новые:

6. **POST /api/admin/upload** ✨
   - Загрузка изображения
   - Body: multipart/form-data с полем `file`
   - Ответ: `{ id, url, fileName, size }`

## 🐛 Известные ограничения

### 1. Локальное хранилище

**Проблема:** Файлы хранятся на сервере приложения

**Решение:** Миграция на AWS S3 / Cloudinary

### 2. Без оптимизации изображений

**Проблема:** Изображения сохраняются в оригинальном размере

**Решение:** Добавить Sharp для автоматического сжатия

### 3. Без вариантов размеров

**Проблема:** Нет thumbnail, medium, large версий

**Решение:** Генерировать несколько размеров при загрузке

### 4. Без очистки неиспользуемых файлов

**Проблема:** Старые фото остаются на диске

**Решение:** Cron задача для очистки orphan файлов
