# Google OAuth — Checklist для проверки

После настройки Google OAuth credentials, проверьте следующее:

## ✅ Backend проверка

- [ ] `.env` содержит корректные `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`
- [ ] `.env` содержит `NEXT_PUBLIC_GOOGLE_CLIENT_ID`
- [ ] База данных обновлена (`npx prisma db push` выполнена)
- [ ] TypeScript компилируется без ошибок (`npx tsc --noEmit`)
- [ ] API endpoint `/api/auth/google` отвечает без ошибок
- [ ] Сервер запускается без ошибок (`npm run dev`)

## ✅ Frontend проверка

- [ ] Страница `/login` отображает кнопку "Continue with Google"
- [ ] Кнопка Google выглядит как официальная (белая, с логотипом)
- [ ] Кнопка не ломает существующий дизайн
- [ ] Разделитель "или" отображается корректно
- [ ] Поля email и password работают как раньше

## ✅ Функциональность — Новый пользователь

- [ ] Нажать "Continue with Google"
- [ ] Выбрать Google аккаунт
- [ ] Пользователь автоматически создаётся в БД
- [ ] Редирект на главную страницу
- [ ] Аватар отображается в header (правый верхний угол)
- [ ] Имя пользователя отображается в header
- [ ] Клик на аватар открывает dropdown menu
- [ ] "Мой профиль" работает
- [ ] Страница профиля показывает Google аватар
- [ ] Страница профиля показывает имя и email из Google

## ✅ Функциональность — Существующий email

- [ ] Зарегистрироваться через email/password
- [ ] Выйти из аккаунта
- [ ] Войти через Google с **тем же email**
- [ ] Система связывает аккаунты (не создаёт дубликат)
- [ ] Google аватар добавляется к существующему аккаунту
- [ ] Выйти
- [ ] Войти через email/password — всё работает
- [ ] Выйти
- [ ] Войти через Google — всё работает

## ✅ Функциональность — Повторный вход

- [ ] Войти через Google
- [ ] Выйти
- [ ] Войти через Google снова
- [ ] Вход работает без ошибок
- [ ] Аватар по-прежнему отображается

## ✅ Функциональность — Session persistence

- [ ] Войти через Google
- [ ] Перезагрузить страницу (F5)
- [ ] Сессия сохраняется
- [ ] Аватар и имя по-прежнему отображаются
- [ ] Закрыть браузер
- [ ] Открыть снова
- [ ] Сессия сохраняется (если не прошло 30 дней)

## ✅ Функциональность — Logout

- [ ] Войти через Google
- [ ] Нажать на аватар в header
- [ ] Нажать "Выйти"
- [ ] Редирект на главную страницу
- [ ] Кнопка "Войти" снова отображается в header
- [ ] Cookie сессии удалена (проверить в DevTools → Application → Cookies)

## ✅ Функциональность — Обычный login

- [ ] Email/password login продолжает работать
- [ ] Форма логина не сломана
- [ ] Validation работает
- [ ] Ошибки отображаются корректно
- [ ] Remember Me работает

## ✅ Функциональность — Ошибки

- [ ] Отменить Google Sign-In (закрыть окно)
- [ ] Ничего не ломается, пользователь остаётся на странице логина
- [ ] Ввести неправильный email/password
- [ ] Ошибка отображается корректно
- [ ] Google OAuth не сломал обработку ошибок

## ✅ Console проверка

- [ ] Открыть DevTools → Console
- [ ] Войти через Google
- [ ] Нет ошибок в console
- [ ] Нет warnings связанных с Google SDK
- [ ] Перейти на страницу профиля
- [ ] Нет ошибок в console

## ✅ Network проверка

- [ ] Открыть DevTools → Network
- [ ] Войти через Google
- [ ] POST `/api/auth/google` возвращает 200 OK
- [ ] Response содержит `{success: true, user: {...}}`
- [ ] Cookie `sc_session` установлена
- [ ] `GOOGLE_CLIENT_SECRET` нигде не передаётся (проверить все запросы)

## ✅ Security проверка

- [ ] `.env` файл не закоммичен в git
- [ ] `.gitignore` содержит `.env`
- [ ] `GOOGLE_CLIENT_SECRET` используется только на сервере
- [ ] Только `NEXT_PUBLIC_GOOGLE_CLIENT_ID` доступен в browser
- [ ] Cookie сессии имеет флаг `httpOnly: true`
- [ ] Cookie сессии имеет флаг `secure: true` (в production)

## ✅ Database проверка

- [ ] Открыть Prisma Studio (`npx prisma studio`)
- [ ] Найти пользователя, который вошёл через Google
- [ ] Поле `googleId` заполнено
- [ ] Поле `googleAvatar` содержит URL аватара
- [ ] Поле `email` содержит email из Google
- [ ] Поле `name` содержит имя из Google
- [ ] Поле `passwordHash` = null для Google-пользователей
- [ ] Поле `roleId` = ID роли "client"

## ✅ Mobile проверка

- [ ] Открыть сайт на телефоне или в DevTools responsive mode
- [ ] Кнопка Google отображается корректно
- [ ] Кнопка не выходит за границы экрана
- [ ] Процесс входа работает на мобильном
- [ ] Аватар отображается в mobile header
- [ ] Mobile menu работает

## ✅ Cross-browser проверка

- [ ] Chrome — работает
- [ ] Firefox — работает
- [ ] Safari — работает
- [ ] Edge — работает
