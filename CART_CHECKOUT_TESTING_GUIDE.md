# Руководство по тестированию корзины и оформления заказа

## Обзор реализации

Реализована полноценная система корзины и оформления заказов с интеграцией Finik Pay для Sierra Coffee.

### Основные компоненты:

1. **CartContext** - управление состоянием корзины (localStorage)
2. **API корзины** - CRUD операции для товаров в корзине
3. **Страница корзины** - /cart с управлением товарами
4. **Страница оформления** - /checkout с формой доставки
5. **API заказов** - создание заказов с Finik Pay
6. **Webhook** - обработка уведомлений от Finik Pay
7. **Страница результата** - /order/[id] с отслеживанием статуса
8. **Админ-панель** - управление заказами

---

## Предварительная подготовка

### 1. Проверка переменных окружения

Убедитесь, что в `.env.local` настроены:

```env
# Database
DATABASE_URL="postgresql://..."

# Finik Pay
FINIK_ENV="prod"  # или "beta" для тестирования
FINIK_API_KEY="your-api-key"
FINIK_ACCOUNT_ID="your-account-id"
FINIK_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----"

# App URL (для webhook и redirect)
NEXT_PUBLIC_APP_URL="https://your-domain.com"
NEXTAUTH_URL="https://your-domain.com"
```

### 2. Запуск приложения

```bash
npm run dev
```

Приложение должно запуститься на `http://localhost:3000`

### Сценарий 5: Интеграция с Finik Pay

**Цель:** Проверить создание платежа и редирект

     - Ошибка сети

**Критические проверки:**
- ✓ Заказ создается в БД (проверьте таблицу `orders`)

- ✓ OrderItems созданы с корректными ценами

### Сценарий 6: Webhook от Finik Pay

**Цель:** Проверить обработку уведомлений об оплате

**Важно:** Webhook приходит от Finik Pay автоматически после оплаты

**Ручное тестирование webhook:**

1. Получите реальный webhook payload от Finik Pay (из логов)
2. Отправьте POST запрос на `/api/finik/webhook`:

```bash
curl -X POST http://localhost:3000/api/finik/webhook \
  -H "Content-Type: application/json" \
  -H "signature: test-signature" \
  -H "x-api-timestamp: $(date +%s)000" \
  -d '{
    "id": "payment-id",
    "transactionId": "txn-123",
    "status": "succeeded",
    "amount": 1000,
    "data": {
      "metadata": "{\"orderId\":\"your-order-id\",\"userId\":\"user-id\"}"
    }
  }'
```

**Ожидаемое поведение:**
- Статус Payment обновился на "success"
- Статус Order обновился на "CONFIRMED"
- В логах видно: "[Finik Webhook] Order confirmed: order-id"

**Критические проверки:**
- ✓ Webhook верифицирует подпись (в prod)
- ✓ Проверяется timestamp (защита от replay атак)
- ✓ Обновляются статусы транзакционно
- ✓ Идемпотентность: повторный webhook не дублирует обработку

## Проверка базы данных

### Таблица Orders

```sql
SELECT * FROM orders ORDER BY created_at DESC LIMIT 5;
```

**Проверьте:**
- order_number уникален и в формате "SC..."
- subtotal, discount_amount, total_amount корректны
- fulfillment_type = "delivery" или "pickup"
- payment_method = "online"
- status меняется с NEW → CONFIRMED → ...

### Таблица OrderItems

```sql
SELECT oi.*, p.title, p.price 
FROM order_items oi
LEFT JOIN products p ON oi.product_id = p.id
WHERE oi.order_id = 'your-order-id';
```

**Проверьте:**
- unit_price - это цена на момент заказа (не текущая!)
- line_total = unit_price * quantity
- modifiers сохранены в JSON

### Таблица Payments

```sql
SELECT * FROM payments WHERE order_id = 'your-order-id';
```

**Проверьте:**
- provider = "finik"
- status меняется: created → pending → success
- amount = order.total_amount
- idempotency_key уникален
- webhook_payload заполнен после получения webhook

### Таблица Cart & CartItems

```sql
-- Для авторизованного пользователя
SELECT c.*, ci.* 
FROM carts c
LEFT JOIN cart_items ci ON c.id = ci.cart_id
WHERE c.user_id = 'user-id';
```

**Проверьте:**
- После оформления заказа cart_items должны очиститься

## Тестирование граничных случаев

### 1. Пустая корзина

- Попытка открыть `/checkout` с пустой корзиной
- **Ожидание:** редирект на `/cart`

### 2. Недоступный товар

```sql
UPDATE products SET is_available = false WHERE id = 'product-id';
```

- Попытка оформить заказ с недоступным товаром
- **Ожидание:** ошибка "Product ... is not available"

### 3. Одновременные заказы

- Откройте 2 вкладки
- В обеих добавьте товары и оформите заказ
- **Проверка:** оба заказа создаются корректно, idempotency_key разные

### 4. Изменение цены товара

```sql
UPDATE products SET price = 9999 WHERE id = 'product-id';
```

- Оформите заказ с этим товаром
- **Проверка:** в OrderItem сохраняется текущая цена 9999, не старая

### 5. Большое количество товаров

- Добавьте 50+ единиц одного товара
- **Проверка:** система обрабатывает корректно, без ошибок

### 6. Специальные символы

- Введите в комментарий: `<script>alert('test')</script>`
- **Проверка:** текст сохраняется как есть, не выполняется

### 7. Повторный webhook

- Отправьте один и тот же webhook 2 раза
- **Проверка:** статус обновляется 1 раз, второй игнорируется

## Известные ограничения

1. **Гостевые заказы:** Корзина в localStorage, не синхронизируется с сервером
2. **Модификаторы:** Сохраняются как массив строк, не связь с Modifier entity
3. **Автообновление:** Работает только на открытой странице заказа
4. **Finik Pay:** Требует реальные credentials для работы

## Решение проблем

### Заказ не создается

**Проверьте:**
1. Логи сервера: `npm run dev` (console output)
2. Network в DevTools: статус ответа `/api/orders`
3. База данных: подключение работает?
4. Корзина: есть ли товары в localStorage/БД?

**Частые ошибки:**
- "Cart is empty" - корзина пуста или не загрузилась
- "Product not available" - товар деактивирован
- "Unauthorized" - нет сессии (для авторизованных)

### Finik Pay не работает

**Проверьте:**
1. `.env.local`: все переменные FINIK_* заполнены?
2. FINIK_ENV: "beta" для тестов, "prod" для продакшена
3. Логи: ищите "[Finik" в console
4. Network: запрос к Finik API прошел успешно?

**Частые ошибки:**
- "Finik credentials are not configured" - нет API key
- "Failed to generate signature" - неправильный private key
- "Payment creation failed" - проблема на стороне Finik

### Webhook не приходит

**Проверьте:**
1. Webhook URL в Finik Pay кабинете
2. URL должен быть публичным (не localhost)
3. Для локальной разработки используйте ngrok:
   ```bash
   ngrok http 3000
   # Используйте ngrok URL в Finik Pay
   ```
4. Логи: ищите "[Finik Webhook]"

### Админка не показывает заказы

**Проверьте:**
1. Роль пользователя: должна быть admin/manager/kitchen
2. API `/api/admin/orders`: отвечает без ошибок?
3. База данных: есть ли заказы в таблице orders?
4. DevTools → Console: ошибки JavaScript?
