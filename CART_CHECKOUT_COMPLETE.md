### ✅ #6. API создания заказа с Finik Pay
**Файлы:** 
- `app/api/orders/route.ts`
- `app/api/orders/[id]/route.ts`

**Реализовано:**
- `POST /api/orders` - создание заказа:
  - Валидация данных клиента
  - Проверка доступности товаров
  - Транзакционное создание Order + OrderItem + Payment
  - Генерация уникального orderNumber
  - Вызов createFinikPayment() для получения URL оплаты
  - Очистка корзины после успешного создания
  - Поддержка гостевых заказов (items в теле запроса)
  - Сохранение цен на момент заказа (snapshot)
  
- `GET /api/orders` - список заказов пользователя
- `GET /api/orders/[id]` - детали заказа с проверкой доступа
- `PATCH /api/orders/[id]` - обновление статуса (только админы)

**Интеграция Finik Pay:**
- Использование lib/finik.ts
- Передача metadata (orderId, userId) для webhook
- Обработка ошибок создания платежа
- Корректный redirect на Finik Pay страницу

### ✅ #7. Webhook Finik Pay
**Файл:** `app/api/finik/webhook/route.ts`

**Реализовано:**
- `POST /api/finik/webhook` - обработка уведомлений:
  - Верификация подписи через verifyFinikWebhook()
  - Проверка timestamp (защита от replay-атак, max 5 мин)
  - Извлечение orderId из metadata
  - Транзакционное обновление Payment и Order
  - Идемпотентность (повторные webhook безопасны)
  - Детальное логирование для отладки
  
- `GET /api/finik/webhook` - health check
- Статусы: succeeded → Payment.success + Order.CONFIRMED
- Статусы: failed → Payment.failed + Order.CANCELLED

## 🎯 Ключевые особенности

### 1. Гостевые заказы
Корзина работает без авторизации через localStorage, что снижает барьер входа для новых клиентов.

### 2. Snapshot цен
Цены сохраняются в OrderItem на момент создания заказа, что защищает от изменений цен в будущем.

### 3. Автообновление статуса
Страница заказа автоматически обновляется каждые 10 секунд, клиент всегда видит актуальный статус.

### 4. Идемпотентность
Повторные webhook и попытки создания заказа безопасны благодаря уникальным ключам.

### 5. Транзакционность
Критичные операции (создание заказа, webhook) выполняются атомарно - либо все, либо ничего.

### 6. Валидация данных
Форма оформления валидирует телефон +996, email, обязательные поля с понятными сообщениями.

## ⚙️ Конфигурация для запуска

### Переменные окружения (.env.local)

```env
# Database
DATABASE_URL="postgresql://user:password@localhost:5432/sierra_coffee"

# Finik Pay
FINIK_ENV="prod"  # или "beta" для тестирования
FINIK_API_KEY="your-api-key-here"
FINIK_ACCOUNT_ID="your-account-id-here"
FINIK_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----
your-private-key-here
-----END PRIVATE KEY-----"

# App URLs (для webhook и redirect)
NEXT_PUBLIC_APP_URL="https://your-domain.com"
NEXTAUTH_URL="https://your-domain.com"
```

### Команды для запуска

```bash
# Установка зависимостей
npm install

# Запуск БД миграций
npx prisma migrate dev

# Запуск dev сервера
npm run dev

# Проект доступен на http://localhost:3000
```
