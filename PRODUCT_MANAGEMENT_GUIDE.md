# Руководство по управлению товарами - Sierra Coffee

## 🎯 Обзор функционала

Реализовано полноценное управление товарами в административной панели Sierra Coffee:

- ✅ Создание товаров через модальное окно
- ✅ Редактирование всех полей товара
- ✅ Загрузка фотографий (JPG, PNG, WebP)
- ✅ Предпросмотр изображений
- ✅ Удаление товаров с подтверждением
- ✅ Управление доступностью и рекомендациями
- ✅ Интеграция с публичным меню

---

## 📦 Создание товара

### Шаг 1: Откройте раздел товаров

1. Войдите в админ-панель: http://localhost:3000/admin/login
2. Перейдите: **Меню → Товары**
3. Нажмите кнопку **"Создать товар"**

### Шаг 2: Заполните форму

Откроется модальное окно с полями:

#### Обязательные поля:
- **Название товара** - например: "Капучино"
- **Цена (сом)** - например: 180
- **Категория** - выберите из списка

#### Дополнительные поля:
- **Объём / вес** - например: "250 мл", "300 г"
- **Состав** - ингредиенты товара
- **Описание** - подробное описание
- **Калорийность** - в ккал
- **Аллергены** - например: "Молоко, орехи"

#### Переключатели:
- **В наличии** - товар доступен для заказа
- **Рекомендуемый товар** - будет отображаться в рекомендациях

### Шаг 3: Загрузите фотографию

1. Нажмите на область **"Загрузить фотографию"**
2. Выберите файл изображения (JPG, PNG, WebP)
3. Максимальный размер: **5 МБ**
4. Изображение автоматически загрузится на сервер
5. Появится предпросмотр загруженной фотографии

**Примечание:** Фотографии сохраняются в `/public/uploads/` и остаются доступными после перезагрузки.

### Шаг 4: Сохраните товар

1. Нажмите кнопку **"Создать товар"**
2. Товар будет добавлен в базу данных
3. Появится уведомление об успешном создании
4. Таблица товаров автоматически обновится

## ✏️ Редактирование товара

### Способ 1: Через таблицу

1. В списке товаров найдите нужный товар
2. Нажмите на кнопку **"Редактировать"** (иконка карандаша)
3. Откроется модальное окно с заполненными данными

### Способ 2: Клик по строке

1. Кликните на любую строку в таблице товаров
2. Откроется форма редактирования

### Изменение данных

Вы можете изменить любые поля:
- Название, цену, категорию
- Объём, состав, описание
- Фотографию (заменить или удалить)
- Доступность и рекомендации
- Калорийность и аллергены

### Замена фотографии

1. В форме редактирования нажмите **"Заменить"**
2. Выберите новое изображение
3. Старое изображение останется в БД (если используется другими товарами)

### Удаление фотографии

1. Нажмите кнопку **"Удалить"** под предпросмотром
2. Поле фотографии очистится
3. При сохранении товар будет без изображения

### Сохранение изменений

1. Нажмите **"Сохранить изменения"**
2. Данные обновятся в базе данных
3. Таблица автоматически обновится
4. Изменения сразу отобразятся в публичном меню

---

## 🗑️ Удаление товара

### Шаг 1: Нажмите кнопку удаления

В таблице товаров нажмите красную кнопку **"Удалить"** (иконка корзины)

### Шаг 2: Подтвердите действие

Появится модальное окно с предупреждением:

> **Удалить товар?**  
> Вы действительно хотите удалить этот товар? Это действие может повлиять на отображение товара в меню.

### Шаг 3: Подтвердите или отмените

- **Отмена** - закрыть окно без изменений
- **Удалить** - удалить товар из базы данных

### Что происходит при удалении:

1. Товар удаляется из базы данных
2. Таблица автоматически обновляется
3. Товар больше не отображается в публичном меню
4. Фотография остаётся в файловой системе (на случай использования другими товарами)

**Примечание:** Если товар связан с существующими заказами, история заказов сохраняется благодаря использованию Prisma relations.

## 🔍 Поиск и фильтрация

### Поиск по названию

1. Введите название товара в поле поиска
2. Нажмите Enter или кликните вне поля
3. Таблица обновится с результатами

### Фильтр по категории

1. Выберите категорию из выпадающего списка
2. Отобразятся только товары этой категории

### Фильтр по доступности

Выберите:
- **Все товары** - показать всё
- **Доступные** - только товары в наличии
- **Недоступные** - только товары без наличия

### Сброс фильтров

Нажмите кнопку **"Сбросить фильтры"** под панелью поиска

## 🌐 Отображение на сайте

### Публичное меню

Все изменения товаров автоматически отображаются на сайте:

**URL публичного меню:** http://localhost:3000/menu

### Синхронизация данных

1. **Создание товара** → сразу появляется в меню
2. **Изменение цены/описания** → обновляется на сайте
3. **Загрузка фото** → отображается в карточке товара
4. **Недоступные товары** → не отображаются в меню или показываются как "Нет в наличии"
5. **Рекомендуемые товары** → показываются в разделе "Рекомендуем"

### API эндпоинты для публичного меню

Товары загружаются через:
- `GET /api/products` - все товары
- `GET /api/products?recommended=true` - рекомендуемые
- `GET /api/products?categoryId={id}` - по категории

## 📊 Структура данных товара

### Таблица `products` в БД

```sql
- id (UUID) - уникальный идентификатор
- categoryId (UUID) - категория товара
- title (String) - название *
- description (String) - описание
- price (Decimal) - цена *
- weightOrVolume (String) - объём/вес
- composition (String) - состав
- calories (Int) - калорийность
- allergens (String) - аллергены
- photoFileId (UUID) - ссылка на файл фото
- isAvailable (Boolean) - в наличии
- isRecommended (Boolean) - рекомендуемый
- isHidden (Boolean) - скрытый
- createdAt (DateTime) - дата создания
- updatedAt (DateTime) - дата обновления
```

### Связи

- `category → menu_categories` - категория товара
- `photoFile → files` - файл фотографии
- `modifiers → product_modifiers` - модификаторы (добавки)

## 🔒 Проверка данных и безопасность

### Валидация на клиенте

1. **Название** - обязательно, не пустое
2. **Категория** - обязательна, выбор из списка
3. **Цена** - обязательна, число > 0
4. **Фото** - тип: JPG/PNG/WebP, размер ≤ 5 МБ

### Валидация на сервере

API проверяет:
- Типы данных полей
- Наличие обязательных полей
- Валидность UUID категории
- Размер и тип загружаемых файлов

### Права доступа

Все операции требуют авторизации администратора:
- `products.view` - просмотр товаров
- `products.create` - создание товаров
- `products.update` - редактирование товаров
- `products.delete` - удаление товаров

**Обычные пользователи (role: client) не имеют доступа к этим операциям.**

### Зависимости

Все необходимые зависимости уже установлены:
- `prisma` - ORM для работы с БД
- `@prisma/client` - Prisma Client
- `fs/promises` - для работы с файлами

### Хранилище файлов

**Текущая реализация:** Локальное хранилище

Файлы сохраняются в `/public/uploads/`:
- Имя файла: `{timestamp}-{random}.{ext}`
- Доступны по URL: `/uploads/{filename}`
- Запись в БД: таблица `files`

**Будущая миграция на облако:**

Для продакшена рекомендуется использовать облачное хранилище:
- AWS S3
- Cloudinary
- Google Cloud Storage
- Azure Blob Storage

Для миграции замените код в `app/api/admin/upload/route.ts`.

## 🐛 Решение проблем

### Ошибка "Файл не загружен"

**Причина:** Нет прав на запись в `/public/uploads/`

**Решение:**
```bash
chmod -R 755 public/uploads
```

### Изображение не отображается

**Причина:** Неправильный путь к файлу

**Проверка:**
1. Откройте консоль браузера (F12)
2. Проверьте URL изображения
3. Убедитесь, что файл существует в `/public/uploads/`

### Товар не создаётся

**Причина:** Ошибка валидации или БД

**Решение:**
1. Откройте консоль браузера
2. Посмотрите ошибку в Network → Response
3. Проверьте обязательные поля
4. Проверьте права администратора

### Модальное окно не открывается

**Причина:** Ошибка JavaScript

**Решение:**
1. Откройте консоль браузера (F12)
2. Посмотрите ошибки JavaScript
3. Перезагрузите страницу
4. Очистите кеш браузера

## 📞 API Документация

### POST /api/admin/upload

Загрузка изображения

**Request:**
```
Content-Type: multipart/form-data
Body: file (File)
```

**Response (200):**
```json
{
  "id": "uuid",
  "url": "/uploads/filename.jpg",
  "fileName": "filename.jpg",
  "size": 125678
}
```

### POST /api/admin/products

Создание товара

**Request:**
```json
{
  "title": "Капучино",
  "categoryId": "uuid",
  "price": 180,
  "weightOrVolume": "250 мл",
  "composition": "Эспрессо, молоко",
  "description": "Описание",
  "photoFileId": "uuid",
  "isAvailable": true,
  "isRecommended": false,
  "calories": 150,
  "allergens": "Молоко"
}
```

**Response (201):**
```json
{
  "id": "uuid",
  "title": "Капучино",
  "price": 180,
  ...
}
```

### PATCH /api/admin/products/{id}

Обновление товара

**Request:** Частичные данные товара

**Response (200):** Обновлённый товар

### DELETE /api/admin/products/{id}

Удаление товара

**Response (200):**
```json
{
  "success": true
}
```
