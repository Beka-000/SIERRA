## Обзор

Реализована полноценная система корзины и оформления заказов для Sierra Coffee:

- ✅ **Корзина** с localStorage для гостей
- ✅ **Оформление заказа** с выбором доставки/самовывоза
- ✅ **Интеграция Finik Pay** для приема платежей
- ✅ **Webhook** для обработки уведомлений
- ✅ **Отслеживание заказа** с автообновлением статуса
- ✅ **Админ-панель** для управления заказами

## Функционал

### Для клиентов

#### 1. Корзина покупок
- Добавление товаров одним кликом
- Изменение количества (+/-)
- Удаление товаров
- Сохранение между сессиями (localStorage)
- Работа без авторизации

#### 2. Оформление заказа
- Форма с контактными данными
- Выбор: доставка или самовывоз
- Валидация полей (телефон +996)
- Добавление комментария к заказу
- Просмотр состава и суммы

#### 3. Оплата через Finik Pay
- Безопасный redirect на платежную страницу
- QR-код для оплаты через приложение
- Автоматическое обновление статуса после оплаты

#### 4. Отслеживание заказа
- Прогресс-бар с текущим статусом
- Автообновление каждые 10 секунд
- Полная информация о заказе
- История статусов

### Для администраторов

#### 1. Список заказов
- Таблица всех заказов
- Фильтры: статус, тип, способ оплаты
- Поиск по номеру, имени, телефону
- Пагинация

#### 2. Управление заказом
- Просмотр полной информации
- Изменение статуса
- Информация о клиенте и доставке
- Состав заказа с ценами

## Быстрый старт

### 1. Установка

```bash
# Клонируйте репозиторий (если еще не сделано)
git clone <repo-url>
cd sierra-coffe

# Установите зависимости
npm install
```

### 2. Настройка

Добавьте в `.env.local`:

```env
# Finik Pay
FINIK_ENV="beta"  # или "prod"
FINIK_API_KEY="your-api-key"
FINIK_ACCOUNT_ID="your-account-id"
FINIK_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----
...
-----END PRIVATE KEY-----"

# App URLs
NEXT_PUBLIC_APP_URL="http://localhost:3000"
NEXTAUTH_URL="http://localhost:3000"
```

### 3. Запуск

```bash
npm run dev
```

Откройте http://localhost:3000/menu

### 4. Тест

1. Добавьте товары в корзину (кнопка "+")
2. Откройте корзину (иконка в navbar)
3. Нажмите "Оформить заказ"
4. Заполните форму
5. Проверьте создание заказа

## API

### Публичные endpoints

#### Корзина

```typescript
GET    /api/cart              // Получить корзину
POST   /api/cart              // Добавить товар
DELETE /api/cart              // Очистить корзину
PATCH  /api/cart/[productId]  // Изменить количество
DELETE /api/cart/[productId]  // Удалить товар
```

#### Заказы

```typescript
POST /api/orders     // Создать заказ
GET  /api/orders     // Список заказов пользователя
GET  /api/orders/[id] // Детали заказа
```

#### Webhook

```typescript
POST /api/finik/webhook  // Обработка уведомлений Finik Pay
GET  /api/finik/webhook  // Health check
```

### Админ endpoints

```typescript
GET   /api/admin/orders       // Список всех заказов (+ фильтры)
GET   /api/admin/orders/[id]  // Детали заказа
PATCH /api/admin/orders/[id]  // Обновить статус
```

## FAQ

### Как работает корзина для гостей?

Корзина хранится в localStorage браузера. При создании заказа данные отправляются в API вместе с формой оформления.

### Можно ли оформить заказ без регистрации?

Да! Система поддерживает гостевые заказы. Нужно только указать имя и телефон.

### Как обновляется статус заказа?

Webhook от Finik Pay автоматически обновляет статус после оплаты. Страница заказа обновляет данные каждые 10 секунд.

### Что делать если Finik Pay не работает?

1. Проверьте credentials в `.env.local`
2. Убедитесь что FINIK_ENV корректен ("beta" или "prod")
3. Проверьте логи сервера - ищите "[Finik"

### Как тестировать webhook локально?

Используйте ngrok для создания публичного URL:

```bash
ngrok http 3000
# Укажите ngrok URL в Finik Pay webhook settings
```

### Что происходит с корзиной после заказа?

Корзина автоматически очищается после успешного создания заказа (и для БД, и localStorage).

### Можно ли изменить статус заказа?

Да, в админ-панели: `/admin/orders/[id]` → кнопка "Изменить статус"

### Сохраняются ли цены товаров?

Да! Цены сохраняются в OrderItem на момент создания заказа (snapshot). Это защищает от изменения цен в будущем.

## Безопасность

### Реализованные меры

✅ **Webhook верификация** - Подпись проверяется публичным ключом Finik  
✅ **Timestamp validation** - Защита от replay-атак (5 минут)  
✅ **Idempotency** - Уникальные ключи предотвращают дублирование  
✅ **RBAC** - Проверка прав доступа для админ API  
✅ **SQL Injection** - Защита через Prisma ORM  
✅ **XSS** - React escaping по умолчанию  

### Рекомендации

- Используйте HTTPS в production
- Храните credentials в безопасности
- Регулярно обновляйте зависимости
- Мониторьте логи на подозрительную активность
