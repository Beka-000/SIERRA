### 4. **Премиальные анимации**

#### Добавлены в `app/globals.css`:

```css
/* Плавающие частицы */
@keyframes float {
  0%, 100% { transform: translateY(0) translateX(0); opacity: 0.2; }
  25%      { transform: translateY(-20px) translateX(10px); opacity: 0.4; }
  50%      { transform: translateY(-40px) translateX(-10px); opacity: 0.2; }
  75%      { transform: translateY(-20px) translateX(5px); opacity: 0.3; }
}
.animate-float {
  animation: float 20s ease-in-out infinite;
}

/* Медленный пульс */
@keyframes pulse-slow {
  0%, 100% { opacity: 0.3; transform: scale(1); }
  50%      { opacity: 0.6; transform: scale(1.02); }
}
.animate-pulse-slow {
  animation: pulse-slow 8s ease-in-out infinite;
}

/* Текстура дерева */
.wood-texture::before {
  background-image: 
    linear-gradient(90deg, transparent 49%, rgba(139,69,19,0.02) 50%, transparent 51%),
    linear-gradient(0deg, transparent 49%, rgba(101,67,33,0.015) 50%, transparent 51%);
  background-size: 40px 40px, 80px 40px;
  opacity: 0.3;
}

/* Градиентный текст */
.text-gradient-gold {
  background: linear-gradient(135deg, #c9a96e 0%, #d4b87a 50%, #c9a96e 100%);
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
}
```
