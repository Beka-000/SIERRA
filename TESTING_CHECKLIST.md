## ✅ Быстрая проверка

### 1. Создание товара (2 мин)

```
1. Откройте: http://localhost:3000/admin/login
2. Войдите: kojomkulov2004@gmail.com / admin1234!
3. Введите OTP код из Telegram
4. Перейдите: Меню → Товары
5. Нажмите "Создать товар"
6. Заполните:
   - Название: "Тестовый Капучино"
   - Цена: 180
   - Категория: выберите любую
   - Объём: "300 мл"
7. Загрузите любое изображение (JPG, PNG)
8. Включите "В наличии"
9. Нажмите "Создать товар"

```
1. Найдите созданный товар в таблице

3. Измените цену на 200
4. Нажмите "Сохранить изменения"
5. Обновите страницу

✅ Ожидается: цена изменилась на 200
```

### 3. Проверка фото после перезагрузки (30 сек)

```
1. Закройте браузер
2. Откройте снова: http://localhost:3000/admin/menu/products
3. Найдите товар

✅ Ожидается: фото отображается (не пропало)
```

### 4. Удаление товара (30 сек)

```
1. Нажмите кнопку "Удалить" (корзина)
2. Подтвердите удаление
3. Проверьте таблицу

✅ Ожидается: товар исчез из списка
```

### 5. Проверка на публичном меню (1 мин)

```
1. Создайте товар (шаг 1)
2. Откройте в новой вкладке: http://localhost:3000/menu

4. Проверьте карточку товара

✅ Ожидается: товар отображается с фото и ценой

- [ ] Загрузка PNG файла → работает
- [ ] Загрузка WebP файла → работает

- [ ] Загрузка файла > 5 МБ → показывает ошибку
- [ ] Предпросмотр изображения → показывается

- [ ] Фильтр "Доступные" → показывает только доступные

- [ ] Новый товар → сразу в меню
- [ ] Изменение цены → обновляется в меню

- [ ] Изменение описания → обновляется в меню

## 🐛 Типичные проблемы

### Проблема: Модальное окно не открывается

**Проверка:**
1. Консоль браузера (F12)
2. Ошибки JavaScript
3. Статус сервера (npm run dev)

### Проблема: Фото не загружается

**Проверка:**
1. Размер файла ≤ 5 МБ
2. Тип файла: JPG, PNG, WebP
3. Права на директорию: `chmod 755 public/uploads`
4. API /api/admin/upload отвечает 200

### Проблема: Товар не сохраняется

**Проверка:**
1. Заполнены обязательные поля
2. Категория существует
3. Права администратора
4. Соединение с БД

### Проблема: Фото пропадает после перезагрузки

**Проверка:**
1. Файл существует в /public/uploads/
2. URL правильный в БД (таблица files)
3. photoFileId записан в products
