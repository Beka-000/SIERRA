# 🧪 Инструкция по тестированию исправления "Cart is empty"

## ✅ Что было исправлено

Ошибка "Cart is empty" при оформлении заказа с товарами в корзине.

**Причина:** API искал корзину в БД для авторизованных пользователей, но товары хранились в localStorage.

**Решение:** API теперь принимает items из body запроса для всех пользователей.

## 🚀 Быстрый тест (5 минут)

### Шаг 1: Запустите проект

```bash
cd /Users/user/Desktop/sierra\ coffee/sierra-coffe
npm run dev
```

Откройте: http://localhost:3000

### Шаг 2: Добавьте товар в корзину

1. Перейдите в меню: http://localhost:3000/menu
2. Найдите "Капучино"
3. Нажмите кнопку "+  В корзину"
4. Проверьте, что в правом верхнем углу появился счётчик: 🛒 1

### Шаг 3: Перейдите к оформлению

1. Нажмите на иконку корзины или перейдите: http://localhost:3000/cart
2. Убедитесь, что отображается:
   - Товар: Капучино
   - Количество: 1
   - Цена: 120 сом
3. Нажмите кнопку "Перейти к оформлению"

### Шаг 4: Заполните форму

На странице оформления заполните:
- **Имя:** Тестовый Пользователь
- **Телефон:** +996700123456
- **Email:** test@example.com (опционально)
- **Способ получения:** Доставка
- **Адрес:** ул. Тестовая, 1

### Шаг 5: Оформите заказ

1. Нажмите кнопку **"Оформление заказа"**
2. Откройте консоль браузера (F12 → Console)

### ✅ Ожидаемый результат:

**В консоли вы должны увидеть:**
```
[Checkout] Submitting order: {
  itemCount: 1,
  totalAmount: 120,
  items: [{productId: "...", quantity: 1, modifiers: []}]
}
```

**Затем одно из двух:**

#### Вариант A: Finik Pay настроен
→ Перенаправление на страницу оплаты Finik Pay

#### Вариант B: Finik Pay НЕ настроен
→ Перенаправление на страницу заказа `/order/[id]`

**❌ Ошибки НЕ должно быть!**

Если видите `Error: Cart is empty` — сообщите, что исправление не сработало.

## 🐛 Что делать при ошибке

### Если видите "Cart is empty":

1. **Откройте консоль браузера (F12)**
2. **Проверьте вывод перед fetch:**
   ```
   [Checkout] Submitting order: {...}
   ```
3. **Если items пустой массив:**
   - Проблема в CartContext
   - Проверьте localStorage: `localStorage.getItem('sierra_coffee_cart')`

4. **Если items есть, но ошибка на сервере:**
   - Проблема в API
   - Проверьте терминал с `npm run dev`
   - Найдите строку `[Orders API] Creating order`

### Если видите другие ошибки:

**"Some products not found"**
→ Товар удалён из БД, очистите корзину

**"Delivery address is required"**
→ Заполните адрес доставки

**"Customer name and phone are required"**
→ Заполните обязательные поля
