## 🔧 Технические детали

### Стек технологий:
- **Next.js 15** (App Router)
- **TypeScript** - без ошибок
- **Prisma** - ORM для работы с PostgreSQL
- **jose** - для JWT токенов
- **React Context API** - для управления состоянием
- **Tailwind CSS** - для стилизации

### Архитектурные решения:

#### Авторизация:
- JWT токены с подписью через `jose`
- Хранение в HttpOnly cookies (защита от XSS)
- Срок действия 30 дней
- Хеширование паролей через SHA-256 + соль
- Проверка сессии на каждом запросе

#### i18n:
- Централизованные переводы в одном файле
- React Context для глобального доступа
- localStorage для персистентности
- Автоопределение языка браузера
- Fallback на русский язык

#### State Management:
- AuthContext для глобального состояния пользователя
- LocaleContext для языка
- Автоматическая синхронизация с сервером
- Loading states для асинхронных операций

## 📝 Примечания

### Для разработчиков:

- **Session Cookie Name**: `sc_session`
- **Locale Storage Key**: `sierra_locale`
- **JWT Secret**: берётся из `process.env.JWT_SECRET` (необходимо установить в production)
- **Default Locale**: `ru` (русский)
- **Session Duration**: 30 дней

### Важные endpoints:

```typescript
// Авторизация
POST   /api/auth/login       // { email, password }
POST   /api/auth/register    // { name, phone, email?, password, confirmPassword }
POST   /api/auth/logout      // (no body)
GET    /api/auth/session     // Проверка текущей сессии

// Страницы
GET    /login                // Форма входа
GET    /register             // Форма регистрации
GET    /profile              // Личный кабинет (требует auth)
GET    /my-bookings          // Мои бронирования (требует auth)
```

### Используемые типы:

```typescript
interface User {
  id: string;
  name: string;
  email: string | null;
  phone?: string;
  role: string;
}

interface SessionData {
  userId: string;
  role: string;
  name: string;
  email: string | null;
}

type Locale = "ru" | "en" | "ky";
```
